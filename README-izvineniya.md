# Извинения ❤️

Личный романтический мини-сайт без связи с MUGENRO.

## Что внутри
- **Первый экран:** большое адаптивное сердце с «Прости меня» на русском и извинениями на других языках.
- **По нажатию:** авторское стихотворение с извинениями.
- **Вопрос:** «Ты простишь меня, красотка?» — кнопки «Да» и «Конечно, кись».
- **Финал:** пышный букет красных роз, салют и персональная благодарность.

## Запуск
Откройте `index.html` в браузере; никакой сборки, сервера или API не требуется. Для общего доступа разместите файлы в корне отдельного репозитория и включите GitHub Pages (Settings → Pages → Deploy from a branch). На GitHub Pages бесплатный публичный сайт доступен по HTTPS.

## Файлы
- `index.html` — страницы и текст.
- `styles.css` — оформление и мобильная адаптация.
- `script.js` — переходы, кнопки и canvas-фейерверки.
- `roses.svg` — оригинальная векторная иллюстрация букета.
- `favicon.svg` — иконка сердечка.

Никакой аналитики, счётчиков или сбора ответов на сайте нет. Всё работает прямо в браузере.
